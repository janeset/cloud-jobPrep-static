# Content to add

Cloud engineer interviews often test Linux and scripting (Bash or Python). Cloud Prep doesn't cover
these in depth yet. Planned lessons, roughly in the order a beginner would need them:

- [ ] **Linux command line depth**: files and permissions (`chmod`, `chown`), users and `sudo`,
  processes (`ps`, `top`, `kill`), services and logs (`systemctl`, `journalctl`), package managers,
  disk and network checks (`df`, `ss`, `curl`), and SSH.
- [ ] **Bash scripting basics**: variables, quoting, `if` and loops, exit codes, pipes and
  redirection, `grep` / `sed` / `awk`, and a small script that automates a lab task.
- [ ] **Python basics for cloud automation**: running scripts, reading JSON and files, calling an
  API, and using the AWS SDK (boto3) or Azure SDK to list and tag resources.
- [ ] **Terraform basics**: providers, resources, variables and outputs, `init` / `plan` / `apply` /
  `destroy`, state, and a first small configuration built step by step (today's DevOps topic and the
  network lab assume this).
